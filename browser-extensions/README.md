# PlatePlan — Browser packages

Independent meal builder & nutrition tools. No restaurant branding.

## Firefox
`releases/extensions/plateplan-firefox.zip`

Load: `about:debugging` → Load Temporary Add-on → `browser-extensions/firefox/manifest.json`

## Edge
`releases/extensions/plateplan-edge.zip`

Load: `edge://extensions` → Load unpacked → `browser-extensions/edge`

## Chrome theme
`releases/extensions/peach-facet-collage-chrome-theme.zip`

Load: `chrome://extensions` → Load unpacked → `browser-extensions/chrome-theme`
