# BJ's Meal Builder

Pick BJ's Restaurant dishes and see the meal's total calories, protein, carbs, fat and sodium. Items with no published value (or listed per slice) are flagged with a "+" instead of guessed, and the meal's allergens are listed. Filter by category, max calories and allergen.

Runs fully in the browser from a bundled `menu.json` (183 items). No tracking, no server.
